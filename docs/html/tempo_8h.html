int dias_entre_datas ( Data inicio,
Data fim )

Calcula a quantidade de dias entre duas datas.

A função verifica se as duas datas são válidas e calcula a diferença absoluta entre elas em dias.

Parameters
inicioA data inicial.
fimA data final.
Returns
A quantidade de dias entre as duas datas. Retorna -1 caso alguma das datas seja inválida.

◆ meses_para_quitar()

int meses_para_quitar ( double divida,
double pagamento,
double taxa )

Calcula em quantos meses uma dívida será quitada.

A função considera uma dívida com juros compostos mensais e pagamentos fixos realizados ao final de cada mês.

Parameters
dividaO valor inicial da dívida. Deve ser maior que 0.
pagamentoO valor pago mensalmente. Deve ser maior que 0.
taxaA taxa de juros mensal em decimal. Deve ser maior ou igual a 0.
Returns
A quantidade de meses necessária para quitar a dívida. Retorna -1 caso algum parâmetro seja inválido ou o pagamento não seja suficiente para reduzir a dívida.

◆ valor_antecipado()

double valor_antecipado ( double parcela,
double taxa,
int dias )

Calcula o valor presente de uma parcela antecipada.

O valor presente é calculado utilizando juros compostos. Os dias de antecipação são convertidos para meses considerando um mês comercial de 30 dias.

Parameters
parcelaO valor original da parcela. Deve ser maior que 0.
taxaA taxa de juros mensal em decimal. Deve ser maior ou igual a 0.
diasA quantidade de dias de antecipação. Deve ser maior ou igual a 0.
Returns
O valor presente da parcela após o desconto pela antecipação. Retorna -1 caso algum parâmetro seja inválido.
