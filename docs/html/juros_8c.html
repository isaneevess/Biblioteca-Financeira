double juros_compostos ( double principal,
double taxa,
int periodos )

Calcula o montante de um investimento ou empréstimo usando juros compostos.

A fórmula para calcular o montante com juros compostos é: montante = principal * (1 + taxa) ^ periodos

Parameters
principalO valor inicial do investimento ou empréstimo.(Deve ser maior ou igual a 0)
taxaA taxa de juros (em decimal) por período. Por exemplo,0.05 para 5%.
periodosO número de períodos de tempo (deve ser maior ou igual a 0).
Returns
O montante total após aplicar os juros compostos(sempre >= 0 em caso de sucesso). Em caso de erro, retorna: JUROS_ERRO_PRINCIPAL_INVALIDO se o valor inicial for negativo, JUROS_ERRO_TAXA_INVALIDA se a taxa for menor que -1.0, JUROS_ERRO_PERIODO_INVALIDO se o número de períodos for negativo.

◆ juros_continuos()

double juros_continuos ( double principal,
double taxa,
double tempo )

Calcula o montante de um investimento ou empréstimo usando juros contínuos.

Diferente dos juros simples e compostos, os juros contínuos são calculados de forma contínua ao longo do tempo. A fórmula para calcular o montante com juros contínuos é: montante = principal * e^(taxa * tempo).

Parameters
principalO valor inicial do investimento ou empréstimo.(Deve ser maior ou igual a 0)
taxaA taxa de juros contínua (em decimal). Por exemplo,0.05 para 5%.
tempoTempo decorrido, em número de períodos (pode ser fracionário, pois a capitalização é contínua, por exemplo, 1.5 para um período e meio).
Returns
O montante final após aplicar os juros contínuos(sempre >= 0 em caso de sucesso). Em caso de erro, retorna: JUROS_ERRO_PRINCIPAL_INVALIDO se o valor inicial for negativo ou JUROS_ERRO_TEMPO_INVALIDO se o tempo for negativo.
