double valor_atual,

Calcula quanto é preciso depositar por mês para atingir a meta.

Considera um saldo inicial e depósitos no fim de cada mês, com juros compostos. O saldo inicial também rende juros, então reduz o valor que falta juntar. A fórmula é: aporte = (meta - valor_atual * (1 + taxa)^periodos) * taxa / ((1 + taxa)^periodos - 1) Se a taxa for 0, o aporte é (meta - valor_atual) / periodos. Se o saldo inicial, com seus rendimentos, já atingir a meta, o aporte é 0.

Parameters
metaO valor que se deseja acumular. (Deve ser maior que 0)
valor_atualO valor já acumulado. Use 0 para começar do zero. (Deve ser maior ou igual a 0)
taxaA taxa de juros mensal (em decimal). Por exemplo, 0.01 para 1%. (Deve ser maior ou igual a 0)
periodosO prazo, em meses. (Deve ser maior que 0)
Returns
O valor a depositar por mês. Retorna -1.0 se algum dos parâmetros for inválido.

Calcula quantos meses são necessários para atingir a meta.

Considera um saldo inicial e depósitos no fim de cada mês, com juros compostos. Se o valor atual já for maior ou igual à meta, o prazo é 0. O resultado pode ser fracionário (por exemplo, 47.3 meses).

Parameters
metaO valor que se deseja alcançar. (Deve ser maior que 0)
valor_atualO valor já acumulado. (Deve ser maior ou igual a 0)
aporte_mensalO valor depositado por mês. (Deve ser maior ou igual a 0)
taxa_mensalA taxa de juros mensal (em decimal). Por exemplo, 0.01 para 1%.
mesesPonteiro onde o prazo, em meses, será gravado. Não pode ser NULL. Em caso de erro, o conteúdo apontado não é modificado.
Returns
META_OK em caso de sucesso; META_ERRO_PARAMETRO se algum parâmetro numérico for inválido; META_ERRO_INALCANCAVEL se a meta nunca puder ser atingida; META_ERRO_PONTEIRO_NULO se meses for NULL.
