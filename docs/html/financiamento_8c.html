Simula o financiamento mês a mês, pagando a parcela normal mais um valor extra.

A cada mês, calcula os juros sobre o saldo devedor, desconta o pagamento total e repete até a dívida zerar.

No final, devolve em quantas parcelas o financiamento termina e quanto de juros foi pago no total.

Parameters
dividaO valor a ser financiado (deve ser maior que 0).
valor_parcelaO valor da parcela mensal (deve ser maior que 0).
extraO valor extra a ser pago além da parcela (deve ser maior ou igual a 0).
taxaTaxa de juros mensal, em decimal (Ex.: 0.02 ao mês; deve ser maior ou igual a 0).
resultadoPonteiro para a struct onde serão gravados em quantas parcelas o financiamento termina e quanto de juros foi pago no total.
Returns
0 em caso de sucesso, -1 se algum parâmetro for inválido ou se o pagamento mensal não cobrir os juros (a dívida nunca seria quitada).

int simular_fin ( double valor,
double entrada,
double taxa,

Simulacao * resultado )

Simula um financiamento com juros compostos.

Calcula o valor da parcela, o total pago, o total de juros pagos e o percentual de juros sobre o valor financiado.

A fórmula para calcular o valor financiado é: financiado = valor - entrada

A fórmula para calcular a parcela com juros é: parcela = financiado * taxa / (1 - (1 + taxa)^-n)

A fórmula para calcular a parcela sem juros é: parcela = financiado / n

A fórmula para calcular o total pago é total_pago = entrada + parcela * n

A fórmula para calcular o total de juros é total_juros = total_pago - valor

A fórmula para calcular o percentual de juros é percentual = (total_juros / financiado) * 100

Parameters
valorO preço total daquilo que será financiado (deve ser maior que 0).
entradaParte do valor que será paga à vista (deve ser maior ou igual a 0 e menor que o valor).
taxaTaxa de juros mensal, em decimal (Ex.: 0.02 ao mês; deve ser maior ou igual a 0).
nNúmero de parcelas mensais (deve ser maior que 0).
resultadoPonteiro para a struct onde serão gravados a parcela, o total pago, o total de juros e o percentual de juros.
Returns
0 em caso de sucesso, -1 se algum parâmetro for inválido.

Calcula o maior valor que pode ser financiado com uma dada parcela.

A fórmula para calcular o maior valor possível com juros é: financiado = parcela * (1 - (1 + taxa)^-n) / taxa

A fórmula para calcular o maior valor possível sem juros é: financiado = parcela * n

Parameters

nNúmero de parcelas mensais (deve ser maior que 0).
resultadoPonteiro para um double onde será gravado o maior valor possível a ser financiado.
Returns
0 em caso de sucesso, -1 se algum parâmetro for inválido.
